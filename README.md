# 📝 Initial NLP Streamlit Application

An interactive web dashboard for Natural Language Processing (NLP) tasks, providing real-time text analysis, sentiment detection, and linguistic metrics.

---

## 📌 Features

* **Text Preprocessing:** Tokenization, stop-words removal, and lemmatization.
* **Sentiment Analysis:** Real-time polarity and subjectivity scoring for input text.
* **Interactive UI:** Dynamic visualizations and controls powered by Streamlit.

---

## 🛠️ Tech Stack

* **Language:** Python 3.11
* **NLP Libraries:** NLTK / TextBlob / SpaCy
* **Frontend Framework:** Streamlit
